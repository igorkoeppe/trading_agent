# Experimentos pré-registrados

Antes de rodar qualquer teste que decide um gate, crie aqui um arquivo
`AAAA-MM-DD_nome.md` com o modelo abaixo e não o altere depois de ver resultados.
Qualquer mudança vira uma nova versão e conta como nova tentativa.

```markdown
# <nome do experimento> — versão 1
Data do registro:
Configuração: A | B | C
Universo (lista fechada):
Estratégias e parâmetros (arquivo em strategies/ e versão):
Período de desenvolvimento / validação / teste final:
Custos assumidos (spread, slippage, taxas):
Métricas:
Critério de sucesso (gate):
Número de variantes já testadas antes desta:
```
